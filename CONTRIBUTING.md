First off, thank you for considering contributing to **RavenLabs**! It's people like you that help us dismantle artificial platform borders and build native, high-performance twins of locked software.

By participating in this project, you agree to abide by our [Code of Conduct](CODE_OF_CONDUCT.md). Please treat all contributors and community members with respect.

## 🚀 How Can I Contribute?

### 1. Reporting Bugs
- Ensure the bug was not already reported by searching on GitHub under [Issues](https://github.com/RaunakxShrivastva/RavenLabs/issues).
- If you're unable to find an open issue addressing the problem, [open a new one](https://github.com/RaunakxShrivastva/RavenLabs/issues/new).
- Be sure to include a **clear title and description**, as much relevant information as possible, and steps to reproduce.

### 2. Suggesting Enhancements
- Check if your idea has already been suggested.
- Open an issue describing the proposed feature, the use case, and how it aligns with RavenLabs' mission of zero-bloat, native computing.

### 3. Submitting Pull Requests
1. **Fork** the repository and create your branch from `main`:
   ```bash
   git checkout -b feature/your-feature-name
   ```
2. Make your changes with clear, descriptive commit messages following the [Conventional Commits](https://www.conventionalcommits.org/) specification:
   - `feat:` for new features
   - `fix:` for bug fixes
   - `docs:` for documentation updates
   - `style:` for styling / CSS changes
   - `refactor:` for code restructuring
3. Ensure the project builds and runs without errors.
4. Push to your fork:
   ```bash
   git push origin feature/your-feature-name
   ```
5. Open a **Pull Request** targeting the `main` branch.

## 🎨 Style Guide & Conventions

- **HTML**: Semantic elements (`<header>`, `<main>`, `<section>`, `<footer>`), valid markup, and accessible ARIA labels.
- **CSS**: Clean custom properties (CSS variables), responsive flexbox/grid layout, smooth 60–120fps transitions.
- **JavaScript**: Modern ES6+, modular structure, no jQuery or bulky external dependencies.
