# Security Policy

## 🔒 Supported Versions

RavenLabs actively maintains security updates and patches for the following versions:

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |
| < 1.0   | :x:                |

---

## 🛡️ Reporting a Vulnerability

The RavenLabs team takes security and privacy very seriously. We appreciate responsible disclosure of any potential security vulnerabilities.

If you believe you have discovered a vulnerability in RavenLabs or any associated utility:

1. **Do NOT open a public GitHub issue.**
2. Send an email to the core maintainer at:
   - **`raunakxshrivastva@gmail.com`**
3. Please include:
   - Description of the issue
   - Step-by-step reproduction instructions or proof-of-concept
   - Impact assessment
4. You will receive an acknowledgment within **48 hours**.
5. Once a fix is verified, a patch will be deployed and you will be credited in the security advisory.

Thank you for helping keep RavenLabs and our users secure.
